# Melody to Chords

Play a single-note melody on your piano; the page turns it into notes, suggests chords per bar and shows which keys to press. Static site, no build step.

**Use on iPad:** open the published URL in Safari (must be HTTPS for the microphone), tap Record, allow the microphone. Optional: Share > Add to Home Screen for a full-screen offline app.

**Deploy:** GitHub repo Settings > Pages > Source: "GitHub Actions". Pushing to `main` then publishes the site (`.github/workflows/pages.yml`).
